About this site

The next version of open-security-summit.org, built in the open.

This is where the next version of the Open Security Summit's website is being built. The official site stays at open-security-summit.org until this one is ready to replace it.

What runs today

The honest line, as of this release:

  • Runs: these pages; the history of the summits; a first cut of the archive, with links to the session pages and recordings on open-security-summit.org; the hosted-projects proposal; the page for the first new working session, php2shell; the first sponsors; this site's build and its gate.
  • Planned, not running: participant pages; the full archive read into data; follow-ups after sessions; personalised paths; event registration.
  • Not decided: dates for the php2shell session, the sessions after it, and London.

The rules this site keeps

The last website was a Hugo site that did a lot that was new, and then stalled under its own exceptions (the story is in the first article). These rules are the lesson, written down so an agent or a person working here can keep them:

  1. One template. Every page uses the same one. A page that seems to need its own is a sign the data is missing a field.
  2. Data in JSON, prose in Markdown. Summits, sessions, events and projects are records in admin/data/. Pages pull them in with a !block line.
  3. No per-year exceptions. A new summit is new data, never new code.
  4. Stdlib only. The build is two short Python files with no dependencies to install, update or break.
  5. The built pages are committed and never edited by hand. The gate rebuilds and fails if anything changed.
  6. Refactor in the same change. When a new need does not fit, the model is changed then, not worked around.
  7. Every push is a release. The version is in admin/build/version.txt and on every page.

How it is made

Pages are written from Dinis Cruz's voice memos and the summit's own records, by an agent working on the site, with the editorial responsibility his. The source is on GitHub, Apache 2.0 for the code and CC BY 4.0 for the content. It is one of the sites of the sgit.ai family, alongside the newsroom.
